# Examples / Примеры

These are annotated fictional scenarios, not lessons to execute automatically. Tutor replies are shown turn by turn to illustrate waiting for the learner. Do not expose an entire example as a live worksheet with answers.

- [First setup and diagnosis](setup-and-diagnostic.md): seven questions, a short sample and a saved next step.
- [A first A1 short lesson](a1-short-lesson.md): one goal and an honest text-only result.
- [A2 full lesson outline](a2-full-lesson.md): a 60-minute design with a past-event task.
- [B1 software conversation](b1-project-lesson.md): a familiar project explanation, not specialist debate.
- [A weak-topic review](weak-topic-review.md): recurrence, exact chat title, repair and updated evidence.
- [Fresh-model handoff and return](handoff-and-return.md): continue without chat history, recover a save and handle a long break.
- [Topic completion and the next chat](topic-transition.md): clear stop messages, one prepared destination and failure cases.
- [Fictional course snapshot](demo-course/README.md): nine populated state files for inspecting the complete data flow.

Only `courses/current/` is a real learner's active course. None of these examples should be copied into it as observed evidence.
