# Fictional course: Alex / Вымышленный курс

Every learner answer, audio observation, date and result here is invented to demonstrate file structure. This is **not** evidence from a real learner or a real voice session. Never load this folder as the active course unless explicitly asked to simulate it.

Alex is a fictional Russian-speaking adult learning German for everyday life and junior software work in Austria. The snapshot ends on 2026-08-12: four completed lessons, an introduction retained across seven days, and a recurring past-tense error that now needs review. Most topics are intentionally untested; the route is not bulk-marked complete.

Start with [PLAN.md](PLAN.md), inspect [TOPICS.md](TOPICS.md), then follow evidence IDs into [LOG.md](LOG.md) and [ASSESSMENTS.md](ASSESSMENTS.md). [ERRORS.md](ERRORS.md) explains the recurring pattern; [REVIEW_QUEUE.md](REVIEW_QUEUE.md) owns its due date; [PHRASES.md](PHRASES.md) and [HOMEWORK.md](HOMEWORK.md) show current practice. [PROFILE.md](PROFILE.md) owns preferences.

For a safe rehearsal write: `Simulate the next lesson using examples/demo-course, without changing any files. Assume today is 2026-08-13.` Expected main topic: DE-A2-03. With simulated date 2026-09-12, use the return-after-break procedure and the due monthly check instead. Do not substitute the simulated date in a real learner course.
