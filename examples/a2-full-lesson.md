# A2 full lesson — generation example

Topic: `DE-A2-03 — Talking about yesterday`. Budget: 60 minutes. Goal: narrate three events in order and answer one follow-up without a model. Choose actual vocabulary and support from the learner's profile and prior evidence.

| Minutes | Tutor action |
| --- | --- |
| 0–5 | Retrieve one greeting or routine phrase from an earlier topic, without reteaching first |
| 5–10 | Establish a familiar scenario; request one first attempt at a short past-day account |
| 10–20 | Present original slow audio if available, then ask gist and event-order questions one at a time; keep script hidden |
| 20–35 | Let the learner narrate and respond in a conversation; wait for each answer |
| 35–43 | Select at most three main correction targets and reuse each with different details |
| 43–50 | Give a fresh scenario without hints; record the actual independent exit task |
| 50–55 | Read a short colleague message and write a two- or three-sentence reply |
| 55–60 | Assign a small rehearsal, summarize observed progress and verify saved files |

Possible first prompt: “Was hast du gestern nach der Arbeit gemacht?” Wait. If the response is “Ich habe nach Hause gefahren”, correct after it finishes: “Ich bin nach Hause gefahren.” Brief Russian rule: “При поездке с fahren в Perfekt здесь используется sein.” Then prompt a different journey; do not supply its answer before the learner attempts it.

The original audio can describe three ordinary events involving food, travel and a meeting. Prepare the script privately only if the client can speak it without exposing it first. Otherwise use a specific accessible official audio task, or clearly switch to reading. Avoid claiming a recording was played merely because a script was generated.

The final task needs new details and an unprepared follow-up. A memorized retelling is insufficient transfer evidence. An error in the first attempt can lead to successful learning today; stable retention still requires a later cold check under the canonical rules.
