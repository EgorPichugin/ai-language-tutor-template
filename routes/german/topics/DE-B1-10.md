# DE-B1-10 — Explaining a software project

- **Can-do:** Explain a familiar software project to a non-specialist.
- **Situation:** Show a small personal application to a colleague.
- **Chunks and patterns:** Die Anwendung hilft … dabei, … zu …; Man kann damit …; Ich habe … entwickelt.; Als Nächstes möchte ich …
- **Grammar in service of the task:** Damit/dabei chunks; simple relative clauses; man; sequence/result connectors.
- **Listening goal:** A clear 90-second project description: identify intended users, main function and current limitation.
- **Speaking goal:** Explain user/problem/function, one personal contribution and the next step in about two minutes; paraphrase one technical word.
- **Practical success:** A non-specialist can state who it is for and what it does; answer a simple follow-up; identify gist and 3 audio details. No architecture defence required.
- **Dependencies:** DE-B1-04, DE-B1-07, DE-B1-08.
- **Return to review:** Jargon replaces explanation or the learner cannot state the project’s purpose in simpler words. Also apply the shared regression and spacing rules in INSTRUCTIONS.md.
- **Thematic chat:** `DE-B1-10 — Explaining a software project`
