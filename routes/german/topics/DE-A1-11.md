# DE-A1-11 — Requests and help

- **Can-do:** Ask for help and clarify a short instruction.
- **Situation:** A course room or shared office.
- **Chunks and patterns:** Können Sie mir bitte helfen?; Ich verstehe das nicht.; Was bedeutet …?; Noch einmal, bitte.; Wo finde ich …?
- **Grammar in service of the task:** können + infinitive; Sie imperative recognition; mir as a request chunk; negation nicht.
- **Listening goal:** Two slowly delivered steps: identify the first action and the object needed.
- **Speaking goal:** Ask for help, request repetition and confirm the first step.
- **Practical success:** Resolve one information gap in a four-turn exchange; identify both heard steps using allowed repetition.
- **Dependencies:** DE-A1-01, DE-A1-08.
- **Return to review:** The learner cannot request clarification and instead guesses incorrectly across sessions. Also apply the shared regression and spacing rules in INSTRUCTIONS.md.
- **Thematic chat:** `DE-A1-11 — Requests and help`
