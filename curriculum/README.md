# Curriculum framework

The complete route currently covers A1 → A2 → B1. Each level has 14 practical blocks, with a transferable can-do index and a link to the fully specified German example:

- [A1](A1.md): simple predictable needs.
- [A2](A2.md): routine problems, plans and short accounts.
- [B1](B1.md): connected familiar interaction and independent practical tasks.

The [German route](../routes/german/README.md) supplies all 42 topic cards. Each card has a stable ID, can-do outcome, situation, chunks, grammar, listening, speaking, task criteria, prerequisites, review trigger and chat title. The shared pedagogy is defined once in [INSTRUCTIONS.md](../INSTRUCTIONS.md).

To adapt another language, preserve purposes where relevant, then author appropriate sentence patterns, pronunciation targets, situations and dependencies. Include everyday reading/writing and mediation alongside oral work. Have a competent speaker/teacher review the adaptation. Do not claim that this topic or grammar sequence is mandated by CEFR.

Future levels can be added as new level files, unique topic codes and route-index entries without changing learner file roles. No B2–C2 curriculum or learning materials are included now.
