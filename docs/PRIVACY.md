# Privacy and personal progress

The public repository contains only reusable materials, blank templates and explicitly fictional examples. Your real learning files are created later in `courses/current/`, which is excluded by `.gitignore` along with private backups, common credential files and audio files.

## What that does and does not protect

Git's ignore file helps avoid accidentally adding new local progress files. It is not encryption or an access control: already tracked files, forced additions, manual uploads, ZIP archives and shared folders can still expose data. Before publishing any modified copy, inspect the actual files being included. Do not place real learner details in the public examples or template files.

The AI client/provider may process the text it reads or receives in chat according to its own settings and terms. Local Markdown storage does not mean offline AI processing. This project does not control provider retention, account access or organizational policy. Consult your chosen provider if these matter for your situation.

## Minimize what you record

Use an alias. Describe a work area broadly. Use fictional addresses, phone numbers, health scenarios, employers and projects during practice. Do not paste identity documents, real medical records, passwords, API keys, confidential code or employer/customer data. No audio uploads are necessary for saving progress; a concise observed result is enough.

For an authentic audio source, save a source link and task reference with short results, not a protected recording or full transcript. The tutor must not contact employers, classmates, medical offices or anyone else on your behalf during a lesson.

## Back up and move

Keep a separate private backup of `courses/current/`. Git history of the public template cannot restore an ignored course. When changing computers, copy the private course into the same relative location in a private project copy. Use only storage that you trust for that purpose.

If you want to reset or delete progress, state that explicitly and decide whether you need a private backup. Deleting local files does not delete copies in backups or a provider's chat history. No cleanup or publication is performed automatically by this template.
