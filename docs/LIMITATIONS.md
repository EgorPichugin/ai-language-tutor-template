# Limits of this template

This is an independent AI tutoring template, not an official course, certified program, full replacement for a teacher, or guaranteed path to B1. Its CEFR references do not establish official alignment. The curriculum and scoring conventions need external review by qualified language educators and trials with real learners.

- **Assessment is provisional.** Internal topic states are local practice decisions. Small samples, uneven skills, model errors and generous prompting can distort a level estimate. A completed B1 route does not equal an exam pass.
- **AI can be wrong.** Grammar corrections, naturalness judgments, cultural notes and generated audio may be inaccurate. Ask a competent teacher/speaker about disputed points; include varied authentic input and human interaction.
- **Text does not prove oral ability.** Listening needs audio; speech assessment needs usable audio input. Recognition transcripts alone omit pronunciation, pauses and other information. Some topics remain learning with partial written gains when oral evidence is missing.
- **A syllabus is not a fixed duration.** Fourteen topics per level do not mean fourteen lessons. Goals, prior knowledge, access needs and retention change the pace. Numerical error thresholds and 3/7/30-day intervals are design heuristics, not validated CEFR cutoffs.
- **German context has limits.** Standard German and a few practical Austrian variants do not train dialect comprehension. Software/KI examples practise familiar explanations, not advanced technical negotiations. Health and administrative examples are language scenarios, not professional advice.
- **Exams need separate preparation.** Official Goethe practice materials help examine formats, but this template is not a complete exam-preparation syllabus. Other exams require their own current official specifications.
- **Client support varies.** File permissions, instruction discovery, context limits, voice and task features differ. Automatic topic chats require the learner's request and an actual creation tool that can use the same local course folder; otherwise the tutor gives a manual title/command. Notifications are not included. The handoff procedure has been checked as instructions and simulated file flows, not with real task creation in every client.
- **Token use varies.** Targeted reads and compact handoffs avoid loading unrelated history by default. The common instructions, relevant evidence and each client’s own context still consume tokens; this release makes no measured cost or savings claim.
- **Saving is cooperative.** Markdown instructions are not enforced software. Simultaneous writes or a model ignoring the save protocol can damage progress; use one writing session and private backups. No reminder runs when the course is closed.

The [quality report](QA.md) records what was actually checked. Improvements and language adaptations should follow [CONTRIBUTING.md](CONTRIBUTING.md).
