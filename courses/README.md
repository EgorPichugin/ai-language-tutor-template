# Your private course / Ваш личный курс

Setup creates `courses/current/` here with nine Markdown files. This folder is intentionally absent in a fresh download. The [clean templates](../templates/state/README.md) are public; your completed copies are private and ignored by Git.

Настройка создаёт здесь папку `current` с девятью файлами прогресса. В свежем шаблоне её нет. Не заполняйте демонстрационный курс своими данными.

Use one course per project copy and one writing chat at a time. For a second language, use another local copy and run setup there. Move the project and its private current folder together when changing computers. A public ZIP or clone contains no personal progress. See [privacy](../docs/PRIVACY.md).
